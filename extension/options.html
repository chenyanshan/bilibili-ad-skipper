B站广告跳过

社区广告优先；没有广告标注时，再由所选 AI 识别。

仅采用“赞助/恰饭”（sponsor）广告。有社区广告就直接跳过，不调用 AI。来源：BilibiliSponsorBlock 社区。

两种方式独立配置。仅调用当前选择的服务，不自动切换，也不共享 Key。

JEV 配置

先分块检查完整字幕，仅对疑似广告选择起止句，边界不确定时复核。默认概率门槛 0.65；越低拦得越多，也越容易误跳。JEV 模式完全不调用 LLM。

LLM 配置

OpenAI 兼容接口。由 LLM 返回字幕起止 ID，评分是模型自评，不是准确率。

默认关闭。JEV 广告概率及全部边界评分均 ≥90%，且实际自动跳过后才投稿；失败不自动重试。LLM 只能手动投稿。投稿是公开的，仅发送广告区间和本机生成的匿名社区 ID，不发送字幕或 API Key。

此选项仅影响 LLM。JEV 始终分块检查全文，疑似广告再确认边界；较长视频可能达到请求预算，届时会提示未检查完。

AI 默认保留不足 20 秒的短广告；社区广告不受此限制。品牌名称仅辅助判断，不直接认定广告；允许少量误跳，可撤销。

Key 仅存本机，不同步。标题、字幕及少量赞助上下文会发送给选定服务。JEV 分块发送完整字幕；LLM 根据省 Token 设置发送候选或完整字幕。不会发送 B 站 Cookie、账号信息或音视频。社区广告不需要字幕；AI 识别需要字幕。社区查询使用视频标识，投稿的广告数据会公开。
