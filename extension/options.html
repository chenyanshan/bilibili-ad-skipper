B站广告跳过

正常看视频，较长的商业植入自动跳过。

两种方式独立配置。仅调用当前选择的服务，不自动切换，也不共享 Key。

JEV 配置

从候选字幕中选择广告开始句、结束句，再继续寻找下一段广告。默认概率门槛 0.65；越低拦得越多，也越容易误跳。JEV 模式完全不调用 LLM。

LLM 配置

OpenAI 兼容接口。由 LLM 返回字幕起止 ID，评分是模型自评，不是准确率。

8 分钟以内直接识别全文；长视频先找线索，可能漏掉隐晦植入。关闭后识别完整字幕。

默认保留不足 20 秒的短广告。名称只用于寻找候选，仍由当前服务判断；允许少量误跳，可撤销。

Key 仅存本机，不同步。标题、候选字幕及少量赞助上下文会发送给选定服务；短视频或关闭省 Token 时发送完整字幕。不会发送 B 站 Cookie、账号信息或音视频。没有字幕的视频暂不支持。
