# B站广告跳过 v0.6.1

设置页的用量统计改为 **最近 24 小时、最近 7 天、最近 30 天**，方便查看短期与月度消耗。三个周期都展示请求数、输入/输出 Token 和参考费用，替代原来的“今日、最近 90 天”。

## 统计口径

- 从当前时刻向前滚动计算 24 小时、7×24 小时、30×24 小时，跨午夜不会清零。
- 未获得完整用量和未估价请求的说明对应近 30 天；旧版只有每日汇总，无法精确换算，因此滚动统计从升级后开始，旧汇总不混入。
- 费用仍为已知官方 JEV 模型的参考估算，不是实际账单。JEV 配置、社区优先和自动跳过行为保持不变。

## 升级

下载本页 ZIP，解压覆盖原扩展目录，在 `chrome://extensions` 点击“重新加载”，再刷新设置页和已打开的 B站视频页。无需卸载，已有设置与本机用量记录保留。

## 验证

`npm run check`、106 项测试及版本标签打包通过。回归覆盖 跨午夜、24 小时/7 天/30 天精确边界、旧汇总隔离与重启恢复及费用累计；真实 Chrome 检查三个统计周期以及桌面、窄屏和中间尺寸显示。
