# B站广告跳过 v0.7.0

设置页新增“插件更新”，可以检测新版本，并提供需要文件夹授权的原地升级功能。

## 使用

- 默认每天检查 GitHub 正式版本，发现新版时图标显示 ↑；也可手动检查、查看说明、下载新版。不会自动安装，不发送 Key、字幕或观看记录。
- 点“准备原地升级”，安装包校验通过后，首次选择 Chrome 当前加载的原安装文件夹并允许写入，再点“安装并重新加载”。以后保留目录记录，浏览器可能再次要求授权。已有设置、Key 和用量保留。
- 覆盖前备份，写入后校验；常规错误尝试回退，也提供“恢复上次备份”。更新时保持页面开启，完成后刷新 B站页面。
- 当前仍为“加载已解压的扩展”，不是商店静默更新。拒绝授权、目录失效或新版需要新权限时，使用下载升级；浏览器崩溃等中断也可下载覆盖恢复。

## 本次升级

**旧版还没有升级器，需要先手动更新这一次：** 下载本页 `bilibili-ad-skipper.zip`，解压覆盖原扩展目录，在 `chrome://extensions` 点击“重新加载”，再刷新设置页和 B站视频页。保持开发者模式开启，不需要卸载或重新填写 Key。

## 验证与限制

检查、135 项测试、版本打包通过。真实 Chrome 验证更新界面、包校验、错误目录拒绝、取消选择、OPFS 文件写入/恢复、备份持久保存，以及临时安装升级后的真实重新加载和存储保留；三个宽度下无横向溢出。

**原生目录授权到整包覆盖的完整流程尚未人工端到端验收**，目前仅测了原生选择取消。OPFS 测试与临时目录的版本切换不能冒充真实用户原地升级成功。功能有下载恢复入口，首次使用请保持页面开启；不保证崩溃或断电时自动回退。
