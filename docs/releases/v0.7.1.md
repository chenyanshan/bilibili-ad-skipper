# B站广告跳过 v0.7.1

简化升级入口，不再把目录绑定、准备安装包和恢复备份作为所有用户都要理解的流程。

- 设置页只显示当前版本、更新提醒和“前往升级”。发现新版后，点击带 ↑ 提醒的插件图标也会直接打开升级页。
- 已授权用户点击“立即升级”，自动完成下载、校验、备份、安装和重新加载；必要时由浏览器再次请求写入许可。
- 未授权用户点击“前往下载新版”进入发布页。首次原地升级授权和恢复备份收进可选设置。
- 不知道原文件夹位置时，可点击“打开当前插件管理页”，在 Chrome 详情的“来源 / 从以下位置加载”查看。插件不能静默获取本机目录或越过文件权限。

## 升级

已有原地升级授权的用户可用原升级入口更新；其他用户下载本页 `bilibili-ad-skipper.zip`，解压覆盖原文件夹，在 `chrome://extensions` 重新加载并刷新 B站页面。不要卸载，Key、设置和用量保持。

## 验证

检查、137 项测试及标签打包通过。Chrome 验证两种升级入口、准确打开本插件管理页并显示实际安装位置，以及设置页/升级页三个宽度的显示。

当前仍是解压安装，不等于 Chrome 商店静默升级。原地升级的原生目录授权到整包覆盖尚未完成人工端到端验收；本版主要改进操作流程，未把此前的隔离测试升级为真实用户安装成功证据。
