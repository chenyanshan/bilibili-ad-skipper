本次在轻量的「B站广告跳过」中接入 [BilibiliSponsorBlock 社区广告数据](https://github.com/hanydd/BilibiliSponsorBlock)，只处理付费赞助广告（`sponsor`）。

- **社区广告优先**：当前视频分 P 已有社区广告时，直接使用标注区间，不调用 AI；无需 API Key 或字幕，短于 20 秒的社区广告也能跳过。
- **没有社区广告，再由 AI 识别**：沿用已选择的 JEV 或 LLM。片头、片尾、自我推广等其他社区类别不阻止 AI；服务失败不会自动切换到另一种服务。
- **新增 JEV 自动投稿开关**：广告概率、起止置信度和所选边界概率全部 ≥90%，且实际自动跳过后，才尝试投稿。投稿前重新查询社区并去重；失败不会反复自动提交。
- **支持手动投稿和失败重试**：JEV 候选可手动提交；LLM 只支持手动投稿，不使用模型自评分自动投稿。面板显示社区/AI 来源及投稿结果。
- **改善播放与恢复**：保留一键撤销、保留片段；切换视频或分 P 时阻止旧结果误跳。Chrome 后台休眠后仍能恢复投稿，无需重新调用 AI。
- **区分无广告、失败和未完成**：完整分析未发现广告的结果只保存在本机；网络错误、缺少字幕、边界矛盾或未完成的分析不会被当作“确认无广告”。不向社区投稿“无广告”记录。

社区查询默认开启，**自动投稿默认关闭**，需要在设置中单独开启。JEV 本地跳过默认门槛仍为 0.65，和社区投稿的 90% 门槛分开。已有 Key、服务地址、模型及识别方式会保留；投稿不包含 Key、字幕或 B站 Cookie。
