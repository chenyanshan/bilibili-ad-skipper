# B站广告跳过 v0.5.0

本版重点改善没有社区标注时的 JEV 自动识别，减少因本地关键词筛选而漏掉的长广告。

## 有什么变化

- **JEV 分块检查全文**：先判断每块是否包含商业推广，仅为疑似广告确认起止。剧情转场、生活体验、产品演示不再因为缺少固定关键词而完全不送入模型。
- **增加边界复核**：临界判断、跨块广告、低边界评分和起止矛盾会按预算复核；仍不确定时保留播放，不凭空补时间。
- **改进长广告处理**：超过 4 分钟的候选不再直接丢弃，合并后额外确认是否为连续推广。近乎整片的区间仍不自动跳过。
- **显示未完成状态**：每次最多 24 次请求；达到预算或边界未确认时明确提示，只使用已确认片段，不能当作“没有广告”。
- 更新算法缓存，避免升级后复用旧版漏检结果。

## 默认行为与额度

社区仍优先：已有 sponsor 标注就采用社区，不调用 AI。JEV 默认概率门槛仍为 0.65，AI 默认保留不足 20 秒的短广告；自动投稿仍默认关闭。JEV 不回退到 LLM。

JEV 现在会分块发送完整字幕，**比旧版关键词筛选消耗更多额度**。原“省 Token”开关保留，但仅影响 LLM。已有服务选择、Key、URL、模型、阈值及开关均保留；安装包不包含任何 Key。

## 实测与限制

21 支有字幕的社区广告视频，使用同一字幕和阈值进行旧流程/新流程真实 JEV 对照：

- 与社区广告时间段相交的时长覆盖：39.1% → **72.6%**。
- 满足默认自动跳过条件的时长覆盖：38.0% → **68.2%**。
- 有重叠的社区广告段：11/26 → **20/26**；有重叠不代表整段覆盖。
- 另测 5 支正常剧情、产品历史和品牌批评等负样本，两组均未识别出广告。
- 26 支总 API 请求数：54 → 173；API 报告输入 Token：201,632 → 776,937。此数不含开发试跑和浏览器验证，不等于货币账单。

这些是开发样本与社区标注的一致程度，不是全站准确率。新版仍有 2 支未完成边界确认；耐克片头、数秒赞助、众筹推广和部分广告铺垫仍可能漏掉。无字幕视频和纯画面植入仍无法靠字幕识别。

## 验证

- 86 项自动化测试通过，涵盖全文召回、跨块、多广告、临界/矛盾边界复核、长广告、预算、缓存升级、配置保留和社区投稿约束。
- 真实 Chrome 加载扩展、真实 JEV 返回后，验证自动跳过与撤销恢复播放。
- 语法、默认配置、版本一致性和打包校验通过；ZIP 根目录直接包含 manifest.json。

## 如何升级

1. 在本页下载 `bilibili-ad-skipper.zip` 并解压。
2. 用新文件替换原先加载的扩展文件夹内容，保持原来的文件夹路径。
3. 打开 Chrome 的 `chrome://extensions`，找到“B站广告跳过”，点击重新加载，再刷新 B站视频页面。
4. 保持原路径重新加载会保留本地设置；不要先卸载扩展，以免删除本地 Key。

新安装请按照 [README 安装步骤](https://github.com/chenyanshan/bilibili-ad-skipper#readme) 操作。不需要安装 Node.js 或 Python。
