# B站广告跳过 v0.6.0

本次仅保留 JEV 广告识别，并在设置页增加 Token 用量和参考费用。

## 功能变化

- 移除 LLM 配置、连接测试和识别调用，只使用 JEV；社区广告依然优先，有社区标注或命中本机缓存时不消耗 JEV 请求。
- 设置页显示当前 Key 在此浏览器中今日、最近 90 天的请求次数、输入 Token、输出 Token 和参考费用。包含连接测试，用量按 UTC 日期记录，升级前的消耗不会补记。
- 官方 JEV 1.13 参考价为每百万输入 Token **0.042 美元**，输出免费，价格核对于 2026-10-01。只有官方接口的已知模型才估价；缺失用量或无法估价的请求单独标明。第三方 Key 的购买成本与实际扣款可能不同，这不是账单。
- 不提供余额查询或剩余天数预测。所有统计只在本机保存，不包含其他设备、其他应用的用量；浏览器中断、网络或存储异常可能漏记。

## 默认行为与升级

已有 JEV 地址、模型、Key、阈值和开关保留。原先选择 LLM 的用户升级后改用 JEV；没有 JEV Key 时只查询社区，不借用 LLM Key。下次保存设置会删除旧 LLM 字段。新安装的 Key 留空，自动投稿默认关闭。

下载本页 ZIP，解压后用新文件覆盖原来的扩展目录，然后在 `chrome://extensions` 点击“重新加载”，刷新已经打开的 B站视频页。无需卸载；卸载会丢失本机配置和统计。统计从本次升级后的请求开始，清除分析缓存不会删除统计。

## 验证

- `npm run check`、105 项自动测试、版本标签打包通过。
- 测试覆盖旧配置升级、JEV 请求路由、并发统计、失败/缺失用量、模型与接口价格隔离、UTC 跨日和 90 天窗口、后台重启、社区/缓存不计费、页面不能读取统计或发起连接测试。
- 真实 Chrome 验证设置保存、旧 LLM 字段移除、保留 JEV 配置、清除缓存保留统计，以及连接测试后用量刷新；连接响应使用 CDP 模拟，未消费真实 Key。
- 已检查桌面 1440×900、窄屏 390×844 和中间宽度 680×900 的实际截图，无横向溢出。此次未重新开展广告准确率评测，沿用此前 JEV 全文识别算法。
