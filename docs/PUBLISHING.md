# 发布准备

GitHub Release 通过 tag 自动发布不含 Key 的 ZIP；尚未提交 Chrome 应用商店。

商店提交前：

1. 完成真实广告样本集验证，检查误跳与漏跳；目前有真实字幕小样本研究和浏览器跳转验证，尚无独立广告准确率评测。
2. 填写发布者信息与支持渠道，公开托管 PRIVACY.md 中的隐私政策并填写 URL。
3. 在 Chrome Web Store 隐私表中如实披露向用户指定 AI 服务发送视频标题/字幕、保存自备 Key，并说明自定义服务需要可选 HTTPS 主机权限。
4. 提交说明：storage 用于配置和有限缓存；scripting 用于复用 B 站页面会话读取播放器字幕元数据；B 站及 hdslb 主机用于字幕；api.typesafe.ai 是首选 JEV 的预设服务；LLM 不预设地址和模型；其余主机仅保存用户自定义接口时请求。
5. 准备商店要求的截图、宣传图及文案，核对名称不会暗示 B 站官方产品；项目已有 16/48/128 像素图标。
6. 使用 npm run build 将 extension 文件夹内容打包，确保 ZIP 根目录为 manifest.json。不要加入个人 Key、测试数据、浏览器配置、截图里的账号信息。

不包含远程执行代码，不使用 eval，不引入外部运行依赖。商店审核结果不能预先保证。
