# 隐私说明

本扩展仅用于识别和跳过 B 站视频内的商业植入。

- 配置 API 后，默认在访问支持的视频页时自动发送该视频标题、候选字幕及少量赞助上下文到用户自行配置的 JEV 或 LLM 服务（只使用用户选中的一种；短视频或关闭省 Token 时发送完整字幕），以识别并跳过广告。可在设置中关闭自动识别。
- JEV 和 LLM 各有独立的 URL、模型与 Key；服务失败不会把字幕或 Key 转发到另一服务。
- API Key 保存在当前 Chrome 配置的本地扩展存储中，只发送给配置的 API 服务，不经过开发者服务器，不使用 Chrome 同步。
- 获取字幕时使用浏览器已有 B 站会话；扩展不会向 AI 发送 Cookie、登录凭证或视频音频。
- 本机最多缓存 100 个视频的标题、识别结果、时间戳及字幕语言。有效期 7 天，设置页可清除缓存；卸载扩展清除本地配置和缓存。
- 不收集分析统计，无广告、遥测或开发者自建后台。AI 服务可能按其自身条款存储请求，使用前请了解所选服务商的政策。
- 权限仅用于本地设置存储、在 B 站页面读取播放器信息、读取字幕及向用户指定的服务发起请求。

正式商店发布时，发布者需要将本说明放在公开可访问的 URL，并补充发布者名称、隐私联系渠道和生效日期。
