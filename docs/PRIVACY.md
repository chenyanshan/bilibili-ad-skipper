# 隐私说明

本扩展用于识别和跳过 B 站视频内的商业植入，接入 [BilibiliSponsorBlock](https://github.com/hanydd/BilibiliSponsorBlock) 的固定社区服务 `https://www.bsbsb.top`。

- 默认查询社区广告，无需 API Key。查询按视频标识进行，只采用 sponsor 广告类别。已有社区广告时不发送字幕给 AI；其他社区分类不参与广告识别。
- 没有社区广告、已配置 AI Key 且开启自动查询时，视频标题、字幕及少量赞助上下文发送给所选 JEV 或 LLM 服务。JEV 分块检查并发送完整字幕；LLM 在短视频或关闭省 Token 时发送完整字幕，其他情况发送本地筛选的候选字幕。可以关闭自动查询或社区功能。
- JEV 与 LLM 各自保存 URL、模型和 Key。只调用选中的服务，失败不跨服务回退。Key 仅存 Chrome 本地扩展存储，不同步，只在认证请求中发送给所选 AI 接口，绝不发送给社区服务。
- 获取字幕时使用已有 B 站会话。AI 和社区请求不会携带 B 站 Cookie、登录凭证或音视频文件。
- AI 分析结果、时间戳、标题及字幕语言最多本机缓存 100 份、7 天。未发现广告的结果也仅在本机缓存，不向社区投稿“无广告”；失败和未完成不会当作无广告。设置页可清除分析缓存。
- 社区查询结果本机缓存最多 100 份、1 小时。投稿使用本机生成的匿名社区 ID，不是 B 站账号；投稿包含视频标识、广告起止区间、分类、视频时长及扩展版本，广告数据会公开。服务方会收到网络连接通常携带的信息，例如 IP 地址，匿名 ID 不代表完全匿名。
- 自动投稿默认关闭，仅另行开启后，对广告概率与所有边界评分均 ≥90% 且实际自动跳过的 JEV 广告尝试投稿。LLM 只允许用户点击手动投稿。不会投稿字幕或 AI Key。
- 本机保留匿名社区 ID 与最多 500 条、7 天的投稿尝试去重记录；失败不自动重试。清除分析缓存不会清除 ID 或投稿记录，卸载扩展会清除本地数据。
- 为恢复 Chrome 后台休眠，可信广告候选临时保存在后台专用会话存储，不含 Key 或字幕；最多 100 个标签页、最长 7 天，关闭浏览器后清除。
- 本扩展没有遥测或开发者自建后台。AI 和社区服务分别适用各自的数据处理政策。

正式商店发布时，发布者需要将本说明放在公开可访问的 URL，并补充发布者名称、隐私联系渠道和生效日期。
